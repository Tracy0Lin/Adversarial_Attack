上一張表用 `served_full`：中風險只要糊完的答案和沒糊的不一樣就擋下。實驗主表不是這套。主表是高風險擋下、低風險放行、中風險只糊 σ = 0.8。下面全部改成主表。

兩階段後仍成功 = C1 + C2 +「原本未成功、糊後變錯」。這一行才對得上實驗的攻擊成功率。

| 類別 | 意思 |
| --- | --- |
| C1 | 一開始攻擊成功，低風險，放行後答案仍錯 |
| C2 | 一開始攻擊成功，中風險，σ = 0.8 之後答案仍錯 |
| C3 | 一開始攻擊成功，低風險，放行後回到原答案 |
| C4 | 一開始攻擊成功，中風險，σ = 0.8 之後回到原答案 |
| C5 | 一開始攻擊成功，高風險，第一階段擋下 |
| C6 | 乾淨圖，中風險，σ = 0.8 之後答案變掉 |
| C7 | 乾淨圖，高風險，第二階段後變攻擊成功 |
| 原本未成功、糊後變錯 | 攻擊圖一開始沒成功，又沒被高風險擋下，放行或糊完之後答案變錯 |

低風險不會進糊圖，所以 C3 在這些表都是 0。高風險在第一階段就擋下，到不了第二階段，所以 C7 也是 0。

難度看乾淨原圖，`question_id` 對 `image_id`。BLIP 用 `question_difficulty/labels.csv`，Florence 用 `question_difficulty/florence/labels.csv`。下面的列都對得到難度。hard 比例只在該格至少 15 筆時寫。明細在 `BLIP_attack/output/VQA/question_difficulty/c1c7_by_difficulty.csv`。
