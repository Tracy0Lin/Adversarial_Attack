# BLIP 自然情境的失敗案例

範圍是實驗一：VLAttack 的 1,000 張攻擊圖，加上對應的 1,000 張乾淨圖。規則和口頭表相同：高風險擋下，中風險只做 σ=0.8，低風險放行。攻擊一開始成功 461 張（46.1%）。防禦後仍成功 240 張（24.0%）。口頭表的 24.1% 就是這一批，重算差 1 張。

## 二、失敗案例分類

| 最終情況 | 張數 |
| --- | --- |
| 低風險，直接放行，答案仍是錯的 | 137 |
| 中風險，σ=0.8 之後答案仍是錯的 | 103 |
| 合計 | 240／1,000 |

137 加 103 是 240，不是 162。162 是另一種算法：中風險只要糊完答案和沒糊的不一樣就擋下，中風險裡還答錯又沒被擋的只剩 25 張，137 加 25 才是 162。口頭表的 24.1% 沒有把這些中風險擋掉，所以中風險要算 103 張。

這 240 張都是攻擊圖。103 張裡，78 張在糊之前就已經答錯，糊完還是錯；另外 25 張糊之前是對的，σ=0.8 把答案改錯了。一開始那 461 張成功攻擊的去向是：137 張低風險仍漏過，78 張中風險糊完仍錯，82 張中風險糊回正確答案，164 張高風險被擋下。

乾淨圖另計。551 張低風險直接放行。88 張被判高風險而擋下，這是誤擋。中風險糊完之後答案變掉的有 10 張。

### 3.3 136002：中風險糊完回到正確答案

問題：what kind of animal is shown?  
正確答案：giraffe  
風險 0.577，中風險。caption 從「兩隻長頸鹿」被改寫，所以進得了中風險。

| 狀態 | 答案 | 是否仍攻擊成功 |
| --- | --- | --- |
| 乾淨圖 | giraffe | 否 |
| 攻擊後 | cat | 是 |
| σ=0.8 之後 | giraffe | 否 |

這題在 C1–C7 裡算被防住，是因為糊完答案和沒糊的不一樣，於是被擋下。記錄裡的 `served_full` 仍是 cat，那是沒糊時的答案，不是 σ=0.8 問出來的 giraffe。若用口頭表那種「中風險只糊、不擋」，這題算修復成功。

## 四、高斯強度對照

第二階段是高斯模糊，不是雙邊濾波。下面是攻擊圖在不同 σ 的答案。主表固定用 0.8。

| σ | 262325003 蔬菜放在什麼上 | 136002 動物 |
| --- | --- | --- |
| 未糊 | plate | cat |
| 0.3 | plate | cat |
| 0.5 | plate | giraffe |
| 0.8（主表） | plate | giraffe |
| 1.0 | plate | giraffe |
| 1.5 | plate | giraffe |
| 正確答案 | bowl | giraffe |

蔬菜那題六個強度都停在 plate。動物那題從 0.5 起回到 giraffe。所以不能說每個強度都無效，也不能從這兩題推出一個共同的失效原因。
