# BLIP 三實驗防禦詳析（第一階段 ±5° + 第二階段高斯）

**設定說明（與你先前表格同一條線）**

| 項目 | 內容 |
|------|------|
| 受害者 VQA | **BLIP VQA**（攻擊、答題、第二階段答案翻轉皆為 BLIP） |
| 第一階段 caption 探針 | **BLIP caption**（`multi_captioner/exp*/blip/`） |
| 防禦管道 | 完整流程 **A3**：Low 放行 → High 攔截 → Mid 用 θ_det 偵測 + θ\* 緩解 |
| 資料來源 | `exp*/blip/summary.json`、`rows_scored.csv`（2026-10 multi_captioner 正式結果） |

**名詞**

- **防禦前 ASR（asr_before）**：攻擊列上，對抗圖答案 ≠ 乾淨圖答案的比例（仍被騙）。
- **防禦後有效 ASR（effective_asr）**：走完 **A3 全管道**後，攻擊列仍騙過 VQA 的比例。
- **ASR 下降**：上兩者相差（百分點）。
- **第一階段分流**：SVM 風險 → Low（≤0.3）/ Mid / High（≥0.7）。
- **Mid 第二階段細表**：只在中風險子集內，用 θ_det=**1.5**、θ\*=**0.8** 做「翻轉偵測 + 緩解」後，答案是否與**同一題乾淨圖的 BLIP 答案**一致（一致＝對該題而言「答對／攻擊被化解」）。

若你手邊舊表出現 **350 / 326** 張 Mid，本次重算為 **338 / 324**（實驗二），以本檔數字為準。

## 一、總體攻擊率（實驗一、二）

兩實驗皆有 **1000 攻擊 + 1000 乾淨** 列；實驗一為自然混合攻擊（約一半 log 成功），實驗二為**全數攻擊成功**建集。

### 1.1 防禦前後有效 ASR（A3 全管道）

|  | 實驗一（混合攻擊） | 實驗二（全成功攻擊） |
| --- | ---: | ---: |
| **防禦前 ASR（初始）** | 46.1% | 99.8% |
| **防禦後有效 ASR** | 17.8% | 27.9% |
| **ASR 下降（百分點）** | **28.3** | **71.9** |

> 說明：你文稿中「初始 46.2% → 43.2%、下降 3%」若是指**另一種統計**（例如僅 Stage1 或僅子集），與本倉庫 **A3 端到端有效 ASR** 不同；論文建議以本表 **17.8% / 27.9%** 為防禦後攻擊成功率。

## 五、簡要解讀

1. **實驗一**：自然 ASR 約 46%，防禦後約 **18%**，適合描述「真實混合流量」。
2. **實驗二**：攻擊幾乎全成功，防禦後 ASR 約 **28%**，並可做消融（見 `../BLIP_attack/output/VQA/multi_captioner/RESULTS_tables.md`）。
3. **實驗三**：無乾淨列，只看攻擊是否被攔下／緩解後是否仍騙過模型；有效 ASR **23.7%**。
4. **Mid 細表**適合寫「第二階段在灰色區域的壓力測試」；整體成效仍以 **A3 有效 ASR** 與 **TPR/FPR** 為主。
