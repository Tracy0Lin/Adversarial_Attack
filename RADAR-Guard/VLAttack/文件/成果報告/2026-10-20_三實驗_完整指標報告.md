## 名詞與算法紀律

| 項目 | 定義 |
|------|------|
| **攻擊成功（無防禦）** | 對抗圖 VQA 答案 ≠ 同圖乾淨參考答案 `vc` |
| **Stage 1** | 原圖 + ±5° 旋轉 caption → 四維角距 → SVM → **Low / Mid / High** |
| **Stage 2** | **僅 Mid** 做 5×5 高斯模糊；θ\*=0.8 緩解用答案、θ_det=1.5 偵測翻轉 |
| **全流程 A3** | High **直接攔截**；Mid 若 θ_det 翻轉答案則攔截，否則以 θ\* 模糊後答案服務；Low **不模糊、直接服務原答案** |
| **Stage 1 混淆矩陣** | 正類 = 攻擊圖（label=1）；預測「可疑」= 進入該規則的風險桶（見下表兩種規則） |
| **AUC** | 以連續 `risk` 分數、攻擊 vs 乾淨（2000 列）；實驗三無乾淨圖 → **N/A** |
| **乾淨誤攔（FPR）** | 乾淨圖被全流程攔截（High 直接攔，或 Mid 且 θ_det 答案翻轉） |
| **乾淨服務率** | 乾淨圖未被攔截、仍送出答案的比例 |
| **乾淨答案被改** | 放行後 `served` ≠ 該圖糊前 VQA（`pred_ref`）。只有 Mid 會糊，Low / High 不會改答案 |
