# 實驗統整

第 1 到第 4 節是實驗一。第 5 節起把實驗二併進來，看整體通過、分階段下降，以及兩次實驗的對照。

答對是指 BLIP 的答案和題目標準答案相同。高斯是 5×5、σ=0.8。糊後答案只存在中風險；低風險、高風險沒有再問過。

實驗一的分流來自 `exp1_routing_breakdown.csv`，糊後答案來自 `steps100_alpha0.002_run1000/sss_per_theta_raw.csv`（kernel=5、σ=0.8：攻擊 391、乾淨 395）。實驗二的分流來自 `exp2_routing_breakdown.csv`，糊後答案來自 `exp2_success1000/sss_per_theta_raw.csv`（攻擊 350、乾淨 326）。五種前處理的整批結果來自 `data_supplement/实验一_全部對抗圖_五種防禦比較.csv`。

## 1. 第一階段

攻擊圖、乾淨圖各 1000 張。這一階段只分流，不改答案。

| | 低風險 | 中風險 | 高風險 | 合計 |
|---|---:|---:|---:|---:|
| 攻擊圖 | 320 | 391 | 289 | 1000 |
| 乾淨圖 | 548 | 395 | 57 | 1000 |

攻擊率 = 中風險攻擊圖 / 1000 = 391/1000 = **39.1%**。

乾淨圖誤判率 =（全部乾淨圖 − 被判成高風險的乾淨圖）/ 1000 = (1000 − 57) / 1000 = 943/1000 = **94.3%**。

分子 943 是沒有被判成高風險的乾淨圖。

## 2. 防禦手法（分母 1000）

高斯這個手法，分母用 1000 張攻擊圖。不能先挑「原本攻擊成功」的 462 張或中風險裡糊前答錯的 165 張，因為那是拿已知答案在篩人。

也不能把沒糊過的圖，用糊前的對錯填成糊後的對錯。低風險 320 張、高風險 289 張都沒有糊後答案，一共 609 張。中風險裡已經看得到反例：糊前答對、糊後改錯的有 26 張。所以「原本攻擊不成功，加上高斯還是不成功」不能拿來補這 609 張。

1000 張裡，只記入實際糊過、並用糊後答案對過標準答案的結果：

| | 張數 | 占 1000 |
|---|---:|---:|
| 做過高斯，糊後答錯 | 112 | 11.2% |
| 做過高斯，糊後答對 | 279 | 27.9% |
| 沒有糊後答案（低 320 + 高 289） | 609 | 60.9% |
| 合計 | 1000 | 100% |

112/1000 是「已測量而且糊後仍答錯」占 1000 張的比例。它不是 1000 張都糊完之後的攻擊率。

這 391 張糊前、糊後的流向是實測，不是假設：

| 攻擊圖（中風險 391） | 糊後答對 | 糊後答錯 |
|---|---:|---:|
| 糊前答對 226 | 200 | 26 |
| 糊前答錯 165 | 79 | 86 |

200 + 26 + 79 + 86 = 391。糊後答對 200 + 79 = 279，糊後答錯 86 + 26 = 112。

上面這段只覆蓋中風險。攻擊紀錄裡另有五種前處理，是 1000 張攻擊圖都做過、也都重新問過的，見下一節。

## 2.1 五種前處理（1000 張攻擊圖都做過）

這五種在產生攻擊時就對全部 1000 張對抗圖做過，並用處理後的答案對過標準答案。乾淨圖沒有納入。分母是 1000。無防禦時答錯 462 張（46.2%）。

這不是第一階段分流之後、只對中風險做的 5×5、σ=0.8。這裡的高斯只指定核大小，沒有另設 σ=0.8。縮放加高斯用的是 3×3 核，縮放範圍 0.9–1.0。

防禦後仍答錯 = 原本就答錯且仍答錯 + 原本答對但被弄錯。後兩欄是對過答案才拆開的，用來看到「原本沒攻成」不會自動維持答對。

| 防禦 | 防禦後仍答錯 | 原本答錯 462：仍答錯 | 原本答錯 462：改對 | 原本答對 538：被弄錯 |
|---|---:|---:|---:|---:|
| 較弱縮放（0.9–1.0） | 384（38.4%） | 344 | 118 | 40（7.43%） |
| 高斯 3×3 | 321（32.1%） | 264 | 198 | 57（10.59%） |
| 較強縮放（0.5–0.7） | 273（27.3%） | 206 | 256 | 67（12.45%） |
| 縮放加高斯 3×3 | 253（25.3%） | 191 | 271 | 62（11.52%） |
| 高斯 5×5 | 233（23.3%） | 171 | 291 | 62（11.52%） |

每一列都對得起來：仍答錯 + 被弄錯 = 防禦後仍答錯，仍答錯 + 改對 = 462。高斯 5×5 是 171 + 62 = 233，也等於 462 − 291 + 62。

1000 張都做過時，高斯 5×5 留下的答錯最少，233/1000 = 23.3%。它同時把原本答對的 538 張弄錯 62 張。較弱縮放弄錯最少，40 張，但防禦後仍答錯最多，384 張。

## 3. 第二階段的分母

第二階段只看進了中風險的圖。分母是攻擊圖和乾淨圖加在一起，不用 1000。

391 + 395 = **786**。

不先假定哪些攻擊已經成功，兩邊都用糊前、糊後的答案去對標準答案。

| | 攻擊圖 | 乾淨圖 | 合計 |
|---|---:|---:|---:|
| 高斯前答對 | 226 | 395 | 621 |
| 高斯後答對 | 279 | 384 | 663 |

合併之後，高斯前答對 621/786 = 79.0%，高斯後答對 663/786 = 84.4%。

## 4. 高斯前後答對，再算 ASR、誤判率、保持程度

表先分成攻擊圖和乾淨圖，最右一欄是總計。答錯 = 該欄張數 − 答對，不另假設。

| | 攻擊圖 | 乾淨圖 | 總計 |
|---|---:|---:|---:|
| 中風險張數 | 391 | 395 | 786 |
| 高斯前能正確回答 | 226 | 395 | 621 |
| 高斯後能正確回答 | 279 | 384 | 663 |
| 高斯前答錯 | 165 | 0 | 165 |
| 高斯後答錯 | 112 | 11 | 123 |

786 是這一池的總張數，用來算合併後答對或答錯的比例。(112 + 11) / 786 = 123/786 = 15.6%，是中風險糊後整體答錯的比例。

ASR 和乾淨圖誤判率分開算，分母用各自的張數。

| 指標 | 算法 | 結果 |
|---|---|---:|
| ASR | 攻擊圖高斯後答錯 / 攻擊圖中風險張數 | 112/391 = **28.6%** |
| 乾淨圖誤判率 | 乾淨圖高斯後答錯 / 乾淨圖中風險張數 | 11/395 = **2.8%** |
| 保持程度 | 高斯後答對 / 高斯前答對 | 見下表 |

保持程度分欄相除。攻擊圖超過 100%，是因為糊後答對從 226 張增到 279 張。

| 保持程度 | 算法 | 結果 |
|---|---|---:|
| 攻擊圖 | 279 / 226 | **123.5%** |
| 乾淨圖 | 384 / 395 | **97.2%** |
| 總計 | 663 / 621 | **106.8%** |

乾淨圖 395 張高斯前全部答對。高斯後仍答對 384 張，改錯 11 張。

## 5. 整體：通過、答對、答錯

這裡算的是管線實際輸出，不是「1000 張都加上高斯」。高風險攔截，沒有答案，不算通過，也不算答對或答錯。低風險用原本的答案。中風險用糊後答案。

通過 = 低風險 + 中風險。攻擊成功率 = 通過後仍答錯 / 1000。乾淨圖保持率 = 通過且答對 / 1000。

### 實驗一

| | 通過 | 攔截（高風險） | 通過後答對 | 通過後答錯 |
|---|---:|---:|---:|---:|
| 攻擊圖 | 711 | 289 | 460 | 251 |
| 乾淨圖 | 943 | 57 | 932 | 11 |

攻擊圖：低風險答對 181、答錯 139；中風險糊後答對 279、答錯 112。181 + 279 = 460，139 + 112 = 251。

乾淨圖：低風險 548 張原本就答對，中風險糊後答對 384、答錯 11。548 + 384 = 932。

攻擊成功率 = 251/1000 = **25.1%**。乾淨圖保持率 = 932/1000 = **93.2%**。

### 實驗二

| | 通過 | 攔截（高風險） | 通過後答對 | 通過後答錯 |
|---|---:|---:|---:|---:|
| 攻擊圖 | 569 | 431 | 160 | 409 |
| 乾淨圖 | 859 | 141 | 842 | 17 |

攻擊圖：低風險 219 張全部答錯；中風險糊後答對 160、答錯 190。0 + 160 = 160，219 + 190 = 409。

乾淨圖：低風險 533 張原本答對。中風險 326 張裡，糊前答對 325、糊前答錯 1；糊後答對 309、答錯 17。其中 17 張是糊前答對、糊後改錯，1 張是糊前答錯、糊後改對。533 + 309 = 842。

攻擊成功率 = 409/1000 = **40.9%**。乾淨圖保持率 = 842/1000 = **84.2%**。

## 6. 實驗二算不算壓力測試，以及分階段下降

實驗二算壓力測試，測的是防禦，不是另一套攻擊。攻擊圖是從實驗一那批攻擊紀錄裡，只留下已經把答案改錯的樣本，取前 1000 張（來源 log 共 2,298 筆，攻擊成功 1,044 筆）。所以無防禦時攻擊成功率是 100%，這是選樣選出來的，不是攻擊變強。乾淨圖是這 1000 張的原圖，不是實驗一那 1000 張乾淨圖。管線和實驗一相同。它回答「攻擊已經成功時，防禦還能拿掉多少」，不能當成混合流量下的部署數字。混合流量看實驗一。

下面的攻擊成功率都是答案不等於標準答案的張數 / 1000。第一階段只攔截高風險，低風險和中風險仍用糊前答案。第二階段只把中風險換成糊後答案。低風險、高風險沒有被假設成「加上高斯之後還是一樣」。

| | 實驗一 | 實驗二 |
|---|---:|---:|
| 無防禦，攻擊成功 | 462（46.2%） | 1000（100%） |
| 第一階段後仍攻擊成功 | 304（30.4%） | 569（56.9%） |
| 第一階段下降 | 158 張，15.8 個百分點 | 431 張，43.1 個百分點 |
| 第二階段後仍攻擊成功 | 251（25.1%） | 409（40.9%） |
| 第二階段下降 | 53 張，5.3 個百分點 | 160 張，16.0 個百分點 |
| 總體下降 | 211 張，21.1 個百分點 | 591 張，59.1 個百分點 |

實驗一：462 − 158 = 304，304 − 53 = 251。158 + 53 = 211。
實驗二：1000 − 431 = 569，569 − 160 = 409。431 + 160 = 591。

相對無防禦的下降比例 = 下降張數 / 無防禦攻擊成功張數。

| | 實驗一 | 實驗二 |
|---|---:|---:|
| 第一階段占原本成功攻擊 | 158/462 = **34.2%** | 431/1000 = **43.1%** |
| 第二階段占原本成功攻擊 | 53/462 = **11.5%** | 160/1000 = **16.0%** |
| 總體 | 211/462 = **45.7%** | 591/1000 = **59.1%** |
| 總下降裡第一階段占 | 158/211 = **74.9%** | 431/591 = **72.9%** |
| 總下降裡第二階段占 | 53/211 = **25.1%** | 160/591 = **27.1%** |

乾淨圖被干擾：第一階段是被判成高風險而攔截，第二階段是中風險糊後答錯。兩段沒有重疊，可以相加。分母都是 1000。

| | 實驗一 | 實驗二 |
|---|---:|---:|
| 第一階段，乾淨圖被攔截 | 57（5.7%） | 141（14.1%） |
| 第二階段，乾淨圖糊後答錯 | 11（1.1%） | 17（1.7%） |
| 總體被干擾 | 68（6.8%） | 158（15.8%） |
| 乾淨圖保持率 | 932（93.2%） | 842（84.2%） |

下降主要在第一階段。兩次實驗都是第一階段拿走約四分之三的下降張數，第二階段約四分之一。實驗二從 100% 降得比較多，但停在 40.9%，仍高於實驗一的 25.1%。乾淨圖被干擾也是實驗二比較高，多出來的主要是第一階段攔截（141 對 57），不是第二階段糊壞（17 對 11）。

影響比較大的是第一階段。做完以後還留著的答錯，則是低風險比中風險多：實驗一 251 張裡有 139 張在低風險、112 張在中風險；實驗二 409 張裡有 219 張在低風險、190 張在中風險。低風險放行之後第二階段碰不到，所以第一階段的缺口比較大。

第二階段自己的池子也沒清完。中風險攻擊圖糊後仍答錯：實驗一 112/391 = 28.6%，實驗二 190/350 = 54.3%。壓力測試下這段更明顯。乾淨圖在這一階段被改錯的比例較小：實驗一 11/395 = 2.8%，實驗二 17/326 = 5.2%。
