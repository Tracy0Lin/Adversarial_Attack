# 🎯 專題報告｜RADAR-VLM 兩階段防禦 × BLIP-VQA 三情境評估

> **📌 一頁摘要（Callout）**  
> 在 **BLIP 視覺問答（VQA）** 上，以 **VLAttack** 產生對抗樣本，並實作 **RADAR-VLM**：第一階段 **±5° 旋轉 + caption 語意分散探測 + SVM 分流**；第二階段 **高斯模糊**（SSS 選緩解強度 θ\*、答案翻轉選偵測 θ_det）。  
> 於 **三種獨立資料情境**（混合攻擊、全成功攻擊、純攻擊）評估 **BLIP caption** 管線；另完成 **四種 caption 探針** 對照（見 `../BLIP_attack/output/VQA/multi_captioner/RESULTS_簡明.md`）。  
> **核心結論**：全管道 A3 在實驗二將有效 ASR 由 **99.8% 降至 27.9%**；實驗一混合流量 **46.1% → 17.8%**。

## 🧭 研究問題

- [ ] **RQ1**：在真實混合流量（攻擊成功與失敗並存）下，兩階段防禦能降低多少 **有效 ASR**？
- [ ] **RQ2**：當攻擊幾乎全數成功時（最壞情況），防禦 **TPR / FPR / 乾淨服務率** 如何權衡？
- [ ] **RQ3**：僅有攻擊圖、無乾淨對照時，移轉自實驗二的參數是否仍能 **攔截與緩解**？
- [ ] **RQ4（延伸）**：換 **ViT-GPT2 / GIT / gemma3** 當 Stage1 caption 探針，路由品質是否仍優於弱探針？

## 🛠 方法總覽

### 攻擊設定

- **輸入**：圖像 + 固定問題文字（只改圖）。
- **成功定義**：對抗圖 VQA 答案 ≠ 乾淨圖 VQA 答案。

### RADAR-VLM 兩階段

| 階段 | 做什麼 | 輸出 |
| --- | --- | --- |
| **Stage 1** | 384×384 原圖 + 10 次 ±5° → 11 句 caption → MiniLM 角距 → 四維特徵 → SVM 風險 | Low / Mid / High |
| **Stage 2** | Mid：5×5 高斯掃 σ；θ\*（SSS）緩解；θ_det（答案翻轉）偵測 | 攔截或送出緩解後答案 |
| **完整管道 A3** | Low 放行；High 攔截；Mid 偵測翻轉則攔，否則 θ\* 緩解 | 有效 ASR、FPR、服務率 |

### 三個獨立實驗情境

| 情境 | 內容 | 規模 |
| --- | --- | --- |
| **實驗一** | 1000 題正常跑 VLAttack → 乾淨 + 攻擊（自然 ASR） | 2000 列 |
| **實驗二** | 1000 乾淨 + 1000 **log 攻擊成功** 攻擊圖 | 2000 列 + **消融 A0–A3** |
| **實驗三** | 僅 1000 攻擊成功；題號／照片與一、二 **不重疊** | 1000 列；SVM/θ **自實驗二移轉** |

## 📊 結果（BLIP caption + BLIP VQA，A3 全管道）

### ✅ 總體攻擊率（防禦前 → 防禦後）

|  | 實驗一（混合） | 實驗二（全成功建集） | 實驗三（僅攻擊） |
| --- | ---: | ---: | ---: |
| **防禦前 ASR** | 46.1% | 99.8% | 99.6% |
| **防禦後有效 ASR** | **17.8%** | **27.9%** | **23.7%** |
| **ASR 下降** | 28.3 pp | 71.9 pp | 75.9 pp |

> **💡 為何實驗二、三「初始」不是 100%？**  
> 建集 log 為 1000/1000 成功；統計時 **重跑 BLIP VQA** 比對乾淨／攻擊答案，有 **2（實二）／4（實三）** 題答案相同 → **99.8%／99.6%**。見 `2026-10-20_BLIP三實驗_防禦詳析.md` 名詞說明。

### ✅ 第一階段分流（各 1000 攻擊 / 1000 乾淨；實三僅攻擊）

**實驗二（壓力測試代表）**

|  | Low | Mid | High |
| --- | ---: | ---: | ---: |
| 攻擊圖 | 220 | 338 | 442 |
| 乾淨圖 | 533 | 324 | 143 |

- 攻擊圖進入 **Mid+High**：**78.0%**
- 乾淨圖 **非 High**：**85.7%**
- 全管道：**TPR 71.5%**｜**FPR 17.6%**｜乾淨服務率 **82.2%**

### ✅ 中風險（Mid）第二階段細表（實驗二）

|  | 攻擊圖 | 乾淨圖 |
| --- | ---: | ---: |
| Mid 張數 | 338 | 324 |
| 緩解前仍為攻擊成功（≠乾淨答案） | 338 | 0 |
| 緩解後仍為攻擊成功 | 337 | — |
| 緩解後乾淨答案被改錯 | — | 2（0.6%） |

> Mid 區主要靠 **全管道路由（含 High 攔截）** 拉低整體 ASR；單靠 Mid 內高斯緩解難以翻回多數全成功攻擊。

### ✅ 三實驗總體比較

| 指標 | 實驗一 | 實驗二 | 實驗三 |
| --- | ---: | ---: | ---: |
| Stage1 AUROC | 0.662 | 0.717 | — |
| 全管道 TPR | 45.4% | 71.5% | 75.9% |

## 🔬 延伸：四種 Caption 探針（答題仍為 BLIP）

| 實驗二 A3｜有效 ASR↓ 越好、FPR↓ 越好 | BLIP | gemma3 | ViT-GPT2 | GIT |
| --- | ---: | ---: | ---: | ---: |
| 有效 ASR | **27.9%** | 27.8% | 39.4% | 37.9% |
| FPR | 17.6% | 16.5% | 14.4% | 23.3% |
| Stage1 AUROC | **0.717** | 0.657 | 0.527 | 0.536 |

**Takeaway**：**BLIP / gemma3** 作 Stage1 探針整體最佳；ViT-GPT2、GIT 僅適合作 **描述分流**，未取代 BLIP 答題。

---

## 💬 討論與限制

1. **有效 ASR** 以端到端 A3 為準，與「僅 Stage1」或「僅 Stage2」消融不同（見 `../BLIP_attack/output/VQA/multi_captioner/RESULTS_tables.md`）。
2. 實驗三 **無 FPR／AUROC**；參數移轉假設部署時有離線校準集（實驗二）。
3. **Caption 實驗 ≠ 更換 VQA 受害者**；若要以 GIT／gemma3 **答題**，需重攻擊與 probe（見 `vqa_backends.py` 試驗線）。
