# 備份_勿執行（只供留存，請勿執行）

這個資料夾只放兩支腳本的備份，**目的是讓流程可被追溯，不是讓人重跑**。

| 檔案 | 為什麼不能執行 |
|---|---|
| `run_end_to_end.py` | 每個里程碑跑完會自動 `git add` / `git commit` / `git push origin HEAD`。在任何 clone 裡執行都會把當下的檔案直接 commit 並推上遠端。 |
| `attack_supervisor.py` | 會反覆重新啟動 `attack_vqa.py`，並在重啟前用 last-good 備份覆寫 `attack_dual_defense_log.json`，同時持續改寫 `output/VQA/` 底下的實驗輸出。執行會覆蓋既有的攻擊紀錄。 |

規則：

1. 不要執行、不要 import、不要排程這兩支腳本。
2. 內含寫死的本機路徑（原作者電腦）。
3. 實驗結果已存在於 `實驗/資料/`，要驗證數字請用 `實驗/程式/3_評估/` 與 `重算工具/` 的唯讀計算腳本。
4. 檔案內容與原電腦上的版本逐位元相同（已用 SHA256 比對）。
