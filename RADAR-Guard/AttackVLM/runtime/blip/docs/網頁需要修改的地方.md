## 現階段可支援的模型用途

預設匯出的是原五折模型。正式案例必須帶正確scenario與image_id，並以原fold模型重播。任意新上傳圖片不能隨便填一個既有ID，當成已驗證案例。

若網站要處理任意新圖片，需要額外產生並驗證明確標示的部署模型；這項工作不等於原五折評估。本包的--include-deployment-model是另列的選用工具，預設不執行，也不將其結果併入正式研究統計。

## 後端回傳與前端映射

- risk_score：原sigmoid margin分數；不可稱為校準後攻擊機率。
- risk_level / action：前端分流依據。
- base_caption：原始模型描述，作實驗對照。
- final_caption：Low的通過描述、Medium修復後描述，High為null。
- repaired_image_path：後端內部路徑，需轉成網站可存取的URL。
- features / captions：研究明細，可放展開區。
- detector_scenario / detector_purpose：標明自然/壓力情境與OOF/部署用途。

Flask環境與attackvlm環境可能不同。現有實驗環境未取得Flask套件，先使用既有網頁環境呼叫指定attackvlm Python的CLI，或另建常駐工作程序；不為了串接而直接修改正在執行實驗的環境。

## 合併驗收

以正式案例核對：輸入圖 → 21句 → 四維特徵 → margin/risk → 分流 → Medium濾波圖片與描述。須涵蓋Clean-Low、Clean-Medium、Attack-High、Attack-Medium、Attack-Low等路徑。

目前僅完成原始碼/CPU/OOF核對，尚未完成這些影像與網站端到端驗收。GIT工作占用GPU時先做CPU匯出及程式合併，模型推論待資源允許再執行。
