# 交接範圍與尚缺項目

這是一份BLIP核心流程的整合交接包，不是所有研究實驗的完整重跑封存。

| 範圍 | 目前狀態 |
|---|---|
| BLIP MF-ii、MF-tt、攻擊描述產生正式原檔 | 已包含 |
| BLIP固定轉換、四維特徵、原五折SVM正式原檔 | 已包含 |
| BLIP雙邊濾波與濾波後描述正式原檔 | 已包含 |
| 自然與壓力情境特徵CSV、OOF結果、最終統計JSON | 已包含 |
| 正式設定、實際環境資訊、單張介面與CLI工具 | 已包含；新介面另標示，尚未GPU端到端驗收 |
| 原環境匯出的五折scaler/SVM模型檔 | 需要執行prepare_cpu_models.sh後，才會加入最終ZIP |
| 模型權重、來源/目標/攻擊/修復圖片 | 未包含；原主機需保留既有資產，跨主機另行移交 |
| 完整資料抽樣/配對manifest建立、Stable Diffusion目標圖生成程式與完整來源目標清單 | 未完整收集，不宣稱包含 |
| 第二階段12組參數搜尋、MSS/IQP/SP/SSS/CIDEr/PSNR等全部離線評估與產報表程式 | 未完整收集；目前只有核心處理原檔、凍結設定及部分結果 |
| 三情境/消融全部啟動器、合併統計程式、完整caption快取、全部執行日誌 | 未完整收集；部分原工作以終端機內嵌程式執行，不能宣稱均有獨立.py |
| ViT-GPT2、GIT、Gemma/Qwen或另一位組員VLAttack的完整流程 | 不在這份BLIP交接包範圍 |

網頁使用的是已凍結的處理設定；12組搜尋屬離線校準。若目的是將已完成BLIP方法接到網站，先完成分類器匯出、案例驗證與接口合併。若目的是在另一台主機從資料準備起完整重跑所有實驗，尚需收集上表未包含項目，這份ZIP不能單獨保證完成。

## 使用者現在要做的事

1. 下載更新後的ZIP，放到老師主機。
2. 解壓到新的獨立資料夾，執行tools/prepare_cpu_models.sh。
3. 工具只用CPU重建原五折並核對既有結果，匯出模型，再產生包含模型的BLIP_Ready_Handoff_日期時間.zip。
4. 將該ZIP交給朋友，先讀README與docs/網頁需要修改的地方.md。
5. GPU資源可用後，再由開發者進行真實案例與網站端到端驗收。

若只是先讓朋友閱讀來源，現在的來源ZIP即可提供；要把可載入分類器一起交付，CPU匯出仍需由使用者或朋友在原主機執行一次。
